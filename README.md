## 校验（发布后适用）

下载后请核对 SHA-256，确认文件未被篡改：

```powershell
Get-FileHash .\<安装包文件名> -Algorithm SHA256
```

与 Releases 页面公布的值逐字符比对。不一致请不要运行。
